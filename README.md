# Cubos da Criação

Jogo original de blocos em 3D com histórias da Bíblia, feito para crianças jogarem e narrarem.

Fases: A Arca de Noé, A Torre de Babel, O Mar Vermelho, Davi e Golias, Daniel na Cova dos Leões.

O jogo é um arquivo só (`index.html`) e roda direto no navegador, no computador ou no celular.
Para jogar junto com amigos, um jogador cria uma sala na tela inicial e passa o código para os outros.
